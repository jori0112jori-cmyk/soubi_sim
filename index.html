📘 このツールの使い方
1) 🧩 編成（タップで編集）
  • 第1〜第3軍（各5枠）＋控え（10枠）を、上のタイルからタップして編集します。
  • 各スロットで キャラ と 武装Lv（0〜30） を設定できます（URは未実装表示）。
  • 10人以上配置すると、🥇 最優先育成まとめ と 🚀 育成効率ランキング が自動更新されます。
  • 「🥇/🥈/🥉/🧰」ボタンで各軍へジャンプできます。
2) 🌍 現在のメタ切り替え
  • ページ上部の「現在のメタ」で 戦車 / 航空 / ロケラン を選ぶと、AIの評価がその環境に寄るように補正されます。
  • 迷う場合は、サーバー上位の主流（多い兵種）に合わせるのが無難です。
3) 📈 戦力入力（任意）＆ 乗り換え推奨度％
  • 「戦力（戦車/航空/ロケラン）」を入れると、兵種ごとの伸び代を推定して 乗り換え推奨度％ を表示します。
  • この推奨度は、環境適応型AI の補正（どの兵種を伸ばすと得をしやすいか）に使われます。
4) 🚀 育成効率ランキングの見方
  • 「🎯 次の到達目標（Lv10 / 20 / 30）」に到達する時の 武装のかけら 効率で並びます。
  • 伸びの表示は体感ベースで、→10：中 / →20：大 / →30：超 になるように調整しています。
💾 データ保存について
入力内容はブラウザの localStorage に自動保存されます（同じ端末・同じブラウザ内）。別端末/別ブラウザには引き継がれません。
